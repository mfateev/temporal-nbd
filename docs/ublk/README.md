# UBLK Phase 0 Artifacts

Status: Draft implementation target for Phase 0 (planning and contract lock).

This folder contains the Phase 0 deliverables defined by the ublk Phase 0 implementation plan.

- `phase0-parity-matrix.md`: capability-by-capability parity target with objective pass/fail checks.
- `phase0-v1-scope.md`: explicit v1 scope, non-goals, and compatibility/migration assumptions.
- `phase0-environment-readiness.md`: host/runtime dependency checklist with `Ready`/`Blocked` status and owners.
- `phase0-interface-contracts.md`: control-plane protocol, operation contracts, lifecycle model, idempotency and observability boundaries.
- `phase0-acceptance-gates.md`: measurable correctness, reliability, operability, and performance gates.
- `phase0-risk-register.md`: risk register, mitigation ownership, sequencing constraints, and Phase 1 entry criteria.

Phase 1 should not start until the `Phase1-Entry-Criteria` section in `phase0-risk-register.md` is fully checked and approved.
